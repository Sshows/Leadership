# Leadership · MGT6702

Сайт: https://leadership-kohl.vercel.app

Все 60 исходных English tickets и полные кейсы, простые русские объяснения, жизненные примеры, ответы преподавателю и фразы для запоминания.

## Режимы

- Учить: пример, объяснение, скрытый ответ и самооценка.
- Квиз: 60 задач с четырьмя вариантами, перемешивание и разбор.
- Устный ответ: вспомнить самостоятельно, затем сравнить с образцом.
- Ошибки возвращаются после двух других попыток; максимум две повторные попытки за подход.
- Счёт с первого раза учитывается отдельно от повторов.
- Прогресс и текущая сессия сохраняются в браузере на устройстве.

Статический сайт без внешних AI API и учётных записей. Исходные материалы опубликованы с явного разрешения пользователя.

## Проверка

`npm test` — 9 проверок перемешивания, повторов, оценки и сохранения.

`npm run build` — проверка полноты 60 билетов и 60 заданий; сборка зависимостей не требуется.

## Публикация

Vercel, production branch main. Конфигурация в vercel.json.
